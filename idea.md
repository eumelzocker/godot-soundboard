Es soll eine Soundboard-App mit Godot 4.7 Engine erstellt werden.
Es sollen Konzepte, Verfahren und Architekturentscheidungen aus ../gamedev-lab/ übernommen und in diesem Geiste erweitert werden, sofern erforderlich.

App verwendet gohud plugin für UI.

App zeigt auswahl für lokales verzeichnis. Bei Auswahl wird verz. nach komp. sound-files gescant und für jeden ein play-button im fenster angezeigt. sounds können mit notes versehen werden, liste der notes kann als yml file gespeichert werden. liste zuletzt verw. verz.

schritt 1: bewerte idee und mache vorschläge für verbesserungen/einfache erweiterungen.
schritt 2: erstelle project-baum mit allen projekt-dateien, git, kopiere benötigte godot-plugins aus ../gamedev-lab/
